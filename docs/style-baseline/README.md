# Frontend Style Baseline

Saved at: 2026-04-29

This folder preserves the current restored frontend visual baseline before the full refactor/prototype work.

- `frontend-index-baseline.html`: current `frontend/dist/index.html`
- `frontend-style-baseline.css`: current compiled CSS asset
- `frontend-app-baseline.js`: current compiled JS asset

Visual direction captured from the current app:

- Neutral black/white/zinc palette
- White rounded cards with light borders and soft shadows
- Black primary actions
- Dense but clean dashboard spacing
- Subtle gray backgrounds and restrained accent colors
