# 知网候选论文归档与放置建议

本目录用于集中保存可用于毕业论文补充引用的中文论文。文件来源以期刊官网、公开题录页、公开 PDF 为主；未绕过知网或机构权限。预印本文件仅作扩展阅读，正式提交前应优先引用已正式发表的期刊版本。

## 放置优先级

优先补充到论文中的顺序建议为：

1. 第一章 1.2 国内外实现现状：补充医疗文本挖掘、医疗大模型、医疗质控系统的研究现状。
2. 第二章 2.1 医疗资料标准化与电子病历文本挖掘：补充 OCR 后文本结构化、命名实体识别、术语标准化和数据治理。
3. 第二章 2.2 医疗大模型、知识增强与 RAG 方法：补充医疗大模型的机会、风险、知识增强和评测治理。
4. 第二章 2.3 Agent 工作流与状态机编排：补充医疗智能体、病历生成智能体和工作流设计。
5. 第三章 3.1 需求分析、3.6 安全与可追溯设计：补充医疗质控、闭环管理、审计追溯和安全边界。

## 建议写入论文的结构

### 1.2 国内外实现现状

可按三段组织：

1. 医疗资料文本挖掘：引用 `01`、`02`、`03`、`04`，说明电子病历文本挖掘和中文 NER 已有较多研究，但多数聚焦单任务抽取。
2. 医疗大模型与知识增强：引用 `06`、`07`、`08`、`09`、`10`，说明大模型在医疗领域有机会，但受准确性、隐私、伦理、责任边界约束。
3. 医疗质控与智能体：引用 `11`、`12`，说明近年来已有系统把 NLP、大模型、RAG、规则库、知识库用于病历质控或病历生成，但本文重点是个人健康资料审计和 LangGraph 状态机可追溯流程。

### 2.1 医疗资料标准化与电子病历文本挖掘

适合引用 `01`、`02`、`03`、`04`、`05`。这一节应强调：医疗文本不是普通文本；中文病历存在术语密集、表达不规范、模板差异、单位差异、隐私治理和版本追溯问题。

### 2.2 医疗大模型、知识增强与 RAG 方法

适合引用 `06`、`07`、`08`、`09`、`10`。这一节应强调：大模型可用于标准化、解释和报告生成，但必须通过知识检索、证据绑定、安全审查和人工边界限制输出。

### 2.3 Agent 工作流与状态机编排

适合引用 `12`，可辅助引用 `07`。这一节应强调：医疗智能体不应只是聊天角色，而应有明确流程、知识库检索、提示工程、工作流设计和结果复核。

### 3.1 需求分析

适合引用 `11`、`13`。可用于说明医疗质控场景需要自动化、实时性、覆盖率、过程监管和闭环管理。

### 3.6 安全与可追溯设计

适合引用 `05`、`06`、`08`、`09`。可用于说明医疗数据治理、隐私保护、模型输出可解释性和责任边界。

## 注意

不要把这些论文原文大段复制进正文。建议做法是阅读后用自己的语言归纳研究对象、方法、结论和局限，并用 Word 交叉引用标注来源。
